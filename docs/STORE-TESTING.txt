The extension needs a companion program. Agents speak MCP, which needs stdio or
a local port. An extension supplies neither.

Needs Node.js 20+. No account.

1. npm install -g ygs-bridge
2. ygs register
3. ygs doctor. Every line must show OK.
4. Click the icon. Set port 12306. Click Connect. The dot turns green.
5. Open news.ycombinator.com. Run chrome_get_web_content. It returns that tab's
   text.

Red dot: restart Chrome, run ygs doctor again.

Source: github.com/Kadajett/yougotserved
