ygs youGotServed

Compact, site-specific browser tools for coding agents.

Give a coding agent one tool that does the job, instead of thirty that describe a browser. Tools run in the browser you already signed in to. There is no second profile and no cookie export.

Every action an agent takes appears on the page, with the arguments it used.

Two parts

The bridge is a program on your computer. It speaks MCP to your agent. The extension drives Chrome. You need both for the browser tools.

The Chrome Web Store still reviews the extension. Until the review ends, build it yourself. It takes a minute, and the steps are in the readme.

Start with the bridge

The bridge alone finds and installs adapters. Nothing opens a tab yet.

npm install -g ygs-bridge
ygs register
ygs doctor

Every line of the doctor report must show OK. Then point your agent at it.

claude mcp add ygs -- ygs-stdio

Add an adapter

An adapter turns one site into a few named tools. It is a JSON file, and never code. It declares the sites it may open, and the host refuses every other address. 

ygs adapter search hacker
ygs adapter add hackernews

The command prints what the adapter can reach, and waits for you to agree.

Sign in, if you want to

Signing in is optional. Nothing needs an account. It puts your name on your ratings, and holds your adapter names when you publish. 

ygs account login

The command prints a code. You approve it in a browser with GitHub. The bridge never sees your password.

Money

There is none. No tool, no adapter and no page is behind a payment, and no plan exists to change that.

A tip jar takes USDC on Base, if you want to send something anyway. It unlocks nothing.
