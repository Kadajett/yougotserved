ygs youGotServed

Compact, site-specific browser tools for coding agents.

Give a coding agent one tool that does the job, instead of thirty that describe a browser. Tools run in the browser you already signed in to, so there is no second profile and no cookie export. 

npm install -g ygs-bridge
Get the extension Source on GitHub Adapter registry

Every action an agent takes appears on the page, with the arguments it used.
